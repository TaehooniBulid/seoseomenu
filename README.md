# 서서분식 앱 다운로드

서서분식 메뉴 및 단체주문 관리용 Android 앱입니다.

## 📱 앱 다운로드

### 👉 [서서분식 앱 다운로드](https://github.com/TaehooniBuild/seoseomenu/raw/refs/heads/main/SeoseoMenu.apk)

위의 **서서분식 앱 다운로드**를 누르면 APK 파일을 다운로드할 수 있습니다.

### 설치 방법

1. 위의 **서서분식 앱 다운로드**를 누릅니다.
2. `SeoseoMenu.apk`를 다운로드합니다.
3. 다운로드가 완료되면 파일을 엽니다.
4. Android에서 설치 허용 여부가 나오면 허용합니다.
5. **설치**를 누릅니다.

> ⚠️ 휴대폰 보안 설정에 따라 "출처를 알 수 없는 앱" 또는 "보안 위험 자동 차단"을 해제해야 할 수 있습니다.
